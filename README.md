# Overview
This repository contains my coursework for the Databases and Analytics module. The brief required me to analyse a fragmented data environment at NorthStar Urban Mobility and Logistics a regional UK transport and logistics company and produce an integrated analytical solution using SQL, R, Python, and MongoDB Atlas.

The analysis investigates four core questions raised in the case study:
1. Where do delivery failures originate, and which hubs underperform?
2. Are customer complaints geographically connected to operational failures?
3. Do manual route overrides indicate driver underperformance?
4. Can a NoSQL document design deliver the integrated view the company currently lacks?

Each notebook in this repository contributes part of the analytical pipeline. The accompanying report submitted separately as a PDF file presents the findings, design decisions, and recommendations.
